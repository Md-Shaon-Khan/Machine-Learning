# Machine Learning

This repository serves as a structured collection of resources, code examples, and Jupyter Notebooks built around the fundamentals of Machine Learning. The primary goal is to document my learning journey and provide a reference for anyone who is starting out in the field. Everything here is written in Python and organized in a way that follows a progressive, topic-by-topic approach.

---

## Overview

Machine Learning is a broad subject that requires both a strong theoretical foundation and consistent hands-on practice. This repository attempts to bridge both. Rather than collecting scattered notebooks, I have organized this work into clearly defined sections that move from core concepts toward more applied, project-level implementations. Each section builds on the one before it.

---

## Repository Structure

**Machine Learning/**  
Contains the foundational notebooks covering core ML concepts. This is where the basics are introduced, including data preprocessing, supervised learning algorithms, model evaluation, and introductory statistical concepts used in the field.

**Machine Learning 2.0/**  
An extension of the foundational content. This section moves into intermediate territory, covering more advanced algorithms, feature engineering techniques, and deeper dives into model performance and tuning.

**Machine Learning 3.0/**  
The most advanced section in the series. This covers topics such as ensemble methods, cross-validation strategies, and more complex modeling pipelines. Work here assumes familiarity with what was covered in the previous two sections.

**Kaggle Competition/**  
Practical competition work. Currently includes a solution notebook for the House Prices: Advanced Regression Techniques competition. This section bridges theory and real-world problem-solving under competition constraints.

**Machine Learning Basics Project/**  
A standalone project applying core ML concepts to a complete problem from data loading through to final predictions. Intended as a capstone for the foundational sections.

**Roadmap Month 1-6/**  
A personal study roadmap broken down by month. This documents the plan I followed while learning, including topics covered, resources used, and milestones. It may be useful for others who want a structured starting point.

**CSV file/**  
Datasets used across the notebooks. These are stored here to keep the notebooks self-contained and reproducible without needing external downloads.

**Books/**  
References to books and reading materials that supported the learning documented in this repository.

## Getting Started

To run the notebooks locally, clone the repository and install the required dependencies.

```bash
git clone https://github.com/Md-Shaon-Khan/Machine-Learning.git
cd Machine-Learning
```

It is recommended to use a virtual environment before installing packages.

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

Then launch Jupyter Notebook:

```bash
jupyter notebook
```

Navigate to the section you want to explore and open the relevant `.ipynb` file.
